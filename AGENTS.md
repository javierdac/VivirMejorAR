# AGENTS.md

Este repositorio es «Guía para vivir mejor (Argentina)» (VivirMejorAR), la adaptación argentina de «高性价比人生指南».

- **Para modificar la guía** (agregar o cambiar entradas, adaptar un capítulo pendiente, tocar las herramientas): las reglas están en [CLAUDE.md](CLAUDE.md) y el formato obligatorio en [ESTILO.md](ESTILO.md). Leelos completos antes de empezar. `book/` (el original chino) no se edita nunca.
- **Para usar la guía y responder preguntas** («¿conviene…?», «¿qué hago primero si…?», «¿es delito…?», «¿qué puedo cobrar?»): seguí [skills/guia-vivir-mejor/SKILL.md](skills/guia-vivir-mejor/SKILL.md). Primero buscá las entradas en `libro/` y después respondé citando «sección N, entrada M». Cómo instalar la skill en otra carpeta: [skills/guia-vivir-mejor/README.md](skills/guia-vivir-mejor/README.md).
